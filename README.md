# 🔐 Password Strength Checker

A beginner-friendly Python project that evaluates the strength of a password using common security rules. It checks whether a password is strong enough by analyzing its length and character types.

## ✨ Features

- ✅ Checks password length (minimum 8 characters)
- 🔠 Detects uppercase letters
- 🔡 Detects lowercase letters
- 🔢 Detects numbers
- 🔣 Detects special characters
- 📊 Calculates a password strength score (0–5)
- 🟢 Classifies passwords as:
  - Weak
  - Medium
  - Strong

## 🛠️ Technologies Used
